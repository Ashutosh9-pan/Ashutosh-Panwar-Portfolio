# Ashutosh Panwar — Portfolio

Professional portfolio website for Ashutosh Panwar, an aspiring AI and Machine Learning Developer.

## Tech stack

- Next.js
- React
- TypeScript
- Responsive CSS

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy

Import this GitHub repository into Vercel. Vercel will automatically detect Next.js and deploy the website.
